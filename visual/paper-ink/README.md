# 纸墨 0.1 · Playground 视觉语言

**设计目标：像一张可以玩的套色版画，而不是一个开了噪声滤镜的游戏。** 对照的是 [How to Say Goodbye](https://store.steampowered.com/app/1709700/How_to_Say_Goodbye/) 的绘本感。信使、刺果敌人、场景和纹理是原创图形。[夜巡环线](../../01-dead-circuit/index.html) 的两个可玩版本已与样板共用 [scene.js](scene.js) 的剪影、场景和棋格几何；横版仍是独立风格试样。

打开 [index.html](index.html)，切换棋盘 / 横版和纸纹强度；无需安装。冻结参考帧：[棋盘](board-preview.png)、[横版](platform-preview.png)。

> 把纸纹调到零：剩下的是画风，加回来的是手感。

每个新 demo 的第一张样稿都先关纸纹。把它和已有样张并排缩到手机宽度：能不能一眼找到主角、危险和下一步能做的事，也认得出是同一系列？如果背景先抢到视线，先改配色或剪影，不加噪声补救。比如环线里的太阳和斗篷同为黄色，太阳掺纸白，最醒目的那一笔黄留给玩家。

## 不随题材改变的部分

| 规则 | 约束 | 可变部分 |
| --- | --- | --- |
| 色彩按职责命名 | 纸白作底、墨青承重；黄是主角 / 主要行动，砖红是危险。背景的黄红必须降对比。 | 场地、远景的颜色，以及纸色与环境色的混合；不要把红黄当装饰撒满全屏。 |
| 先画剪影 | 玩家用一个稳定的大轮廓，敌人用破碎、尖锐的轮廓。每个普通物件一个主色、一个暗面、一个识别细节。 | 换游戏可以换角色，不必都戴帽子；俯视、斜视、横版都可以。 |
| 光是印出来的 | 明暗用有边界的色块；投影硬边、同向。不靠发光、金属反射或模糊投影区分交互物。 | 平台侧壁可用排线，路面可留白，不是每个面都要纹样。 |
| 信息不吃墨 | 标题可用衬线，操作和数值用清晰的黑体。主要决策占一组，辅助信息按需展开。 | 棋盘优先看走向和格子，动作游戏优先看边缘、危险和落脚点。品牌名不必常驻游戏 HUD。 |

六个基础色和材质默认值只在 [paper.css](paper.css) 定义。暗面用现有油墨混色，不给每个道具新造一种主色。交互不能只靠颜色：同时用形状、按下状态、描边或短标签。

## 接到下一个 demo

**DOM / SVG / Canvas 2D：** 引入 `paper.css`，一起保留相对路径下的 `paper-grain.png`。给不透明的场景容器加 `pi-print`，把 HUD、数字与焦点框放在其外或较高层级的 `pi-hud` 中。画布本身是替换元素，要把类加在它外面的容器，不要直接加在 canvas 上。游戏逻辑不用认识材质。

```html
<link rel="stylesheet" href="../visual/paper-ink/paper.css">
<div class="pi-print">
  <canvas aria-label="游戏场景"></canvas>
  <div class="pi-hud">生命 6 / 7</div>
</div>
```

**WebGL2：** [paper.frag](paper.frag) 是可用的 GLSL ES 3.00 片元着色器。先把场景画入一张不透明纹理，再画覆盖视口的三角形，最后画 HUD。用 shader 的项目不要再启用 CSS 纸纹。当前网页样板演示 CSS 路径；shader 另用实际 WebGL2 色块绘制检查。

| Uniform | 接入约定 |
| --- | --- |
| `uScene` | 合成完毕的不透明彩色场景，底部为 UV 原点；样板公式处理的是显示编码 RGB。线性渲染器要在色调映射后转换到显示编码再混合，避免重复 gamma。 |
| `uGrain` | `paper-grain.png` 作为灰度**数据**读入，非 sRGB；上传时首行对应纹理 v=0，不翻转。两个轴设为 REPEAT，常规采样 LINEAR。 |
| `uViewportPx` | 当前全屏 pass 的实际 framebuffer 宽高（viewport 从 0,0 开始）。 |
| `uPixelRatio` | framebuffer 像素 / 逻辑像素；有 render scale 时不要直接照搬设备 DPR。 |
| `uPeriod`, `uStrength` | 对应 CSS 中的 `--pi-period`（默认 256 逻辑像素）与 `--pi-grain`（默认 .47）；关纹理用 0。 |

**材质配方。** 共用一张 256×256 的无缝、固定种子的灰度小图。细粒占 72%，4 像素尺度的纸齿占 19%，32 像素尺度的油墨不均占 9%（生成时的振幅权重）。用柔光将其混入底色，再在原色和混合色之间按强度插值。噪声以屏幕逻辑像素定位，不随镜头拉伸、不传时间，不要每帧换随机数。GPU 路径每像素两次取样：一次场景，一次纸纹；仍需在目标设备测量完整后处理的代价。

PNG 已包含。只在改配方时运行 `node make-grain.mjs` 重建。即使材质强度归零，形状、配色与投影仍应有同一品牌的辨识度。

## 如何迭代

1. 先在这里改，而不是在每个 demo 复制色值或各写一份噪声。每次只改一个变量；用同样的两帧，同时看纹理开 / 关和窄屏。远看先认主角、威胁、路线，近看才见纸纹。
2. 试新题材时先替换场景色和剪影；玩家色 / 危险色、色块光影和 UI 清晰度保持不变。纸感不是必须套在全屏上的效果：密集弹幕、细小棋子都可以局部减弱或关掉。
3. 确认后更新样张、版本号和下方记录。调整默认参数升小版本；改变色彩语义或材质接入约定，保留旧主题副本后再迁移，不让旧实验悄悄变样。
